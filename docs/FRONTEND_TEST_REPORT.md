## Найденные проблемы

### P1: Кнопка "Редактировать" видна для обычного пользователя
- **Серьёзность:** 🔴 Critical (Security/RBAC)
- **Страница:** `/players/{id}` (детальная страница игрока)
- **Описание:** Кнопка "✏️ Редактировать" отображается для обычного пользователя (role=user). По設計 кнопка должна быть скрыта через Alpine.js `x-show="isAdmin"`.
- **Влияние:** Любой авторизованный пользователь может перейти на форму редактирования игрока. Серверная защита (web.py).performяет редирект, но UI не должен показывать кнопку.
- **Шаги воспроизведения:**
  1. Залогиниться как `user/user123`
  2. Перейти на `/players/1`
  3. Увидеть кнопку "✏️ Редактировать"
- **Ожидаемое:** Кнопка скрыта для non-admin
- **Рекомендация:** Проверить `x-show="isAdmin"` в `players/detail.html` — возможно, Alpine.js компонент не имеет доступа к переменной `isAdmin` или используется неправильный `x-data` контекст.

### P2: Колонка "Турнир" пуста в списке игр игрока
- **Серьёзность:** 🟡 Medium (UX)
- **Страница:** `/players/{id}` (блок "История игр")
- **Описание:** Все строки в колонке "Турнир" отображают "—" вместо названия турнира.
- **Влияние:** Пользователь не может определить, в каком турнире была сыграна партия.
- **Шаги воспроизведения:**
  1. Залогиниться
  2. Перейти на `/players/1`
  3. В блоке "История игр" kolонка "Турнир" = "—"
- **Рекомендация:** Проверить API `/api/players/{id}/games` — возвращается ли `tournament_name` или `tournament_id`. Возможно, нужно добавить JOIN в запрос или отображать ID турнира как ссылку.

### P3: Избранные игроки отображают "—" вместо данных
- **Серьёзность:** 🟡 Medium (UX)
- **Страница:** Дашборд `/` (блок "Избранные игроки")
- **Описание:** Блок "⭐ Избранные игроки" для пользователя user показывает "—" вместо имён и рейтингов избранных игроков. Seed создаёт 3 избранных для user.
- **Влияние:** Функция избранного не работает корректно на дашборде.
- **Рекомендация:** Проверить формат ответа API `/api/favorites` — возможно, структура `data[i].player.name` не совпадает с ожидаемой в JS-обработчике `htmx:afterSwap`.

## Позитивные замечания

1. ✅ **Аутентификация** работает безупречно: логин, логаут, JWT в localStorage + HttpOnly cookie
2. ✅ **RBAC на сервере** корректен: все admin-эндпоинты защищены `Depends(get_current_admin)`, веб-роуты редиректят
3. ✅ **HTMX** корректно загружает данные: топ-10, турниры, партии, статистика
4. ✅ **Alpine.js** компоненты работают: авторизация, пагинация, графики, формы
5. ✅ **Chart.js** графики: line chart (рейтинг) и doughnut chart (статистика) — dropdown с 31 игроком
6. ✅ **Фильтры и поиск** работают через HTMX с debounce
7. ✅ **Турнирная таблица** (standings) корректно отображает все данные
8. ✅ **Партии по турам** — полная информация по всем 8 турам
9. ✅ **CSV экспорт/импорт** — функционал присутствует
10. ✅ **SSE** EventSource подключается к `/api/events`
11. ✅ **Адаптивный дизайн** — CSS стили, мобильное меню
