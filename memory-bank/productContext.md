# Product Context: Chess Tracker

## Почему этот проект существует
Учебный проект для демонстрации навыков full-stack разработки с современным стеком технологий. Проект показывает умение работать с:
- Python-бэкендом (FastAPI + SQLAlchemy)
- Реляционными базами данных (PostgreSQL)
- Фронтендом без тяжёлых JS-фреймворков (HTMX + Alpine.js)
- Docker-контейнеризацией
- CI/CD практиками (GitHub Actions)
- Микросервисной архитектурой (отдельный Telegram-bot)

## Проблемы, которые решает проект
1. **Отслеживание турниров**: шахматные болельщики хотят видеть расписание, результаты и турнирные таблицы в одном месте
2. **История рейтингов**: отслеживание изменения рейтинга игрока во времени
3. **Уведомления**: оперативное получение результатов партий через Telegram
4. **Статистика**: анализ результатов игроков (head-to-head, проценты побед)

## Как это должно работать
- Администраторы создают турниры, добавляют игроков, вводят результаты партий
- Обычные пользователи просматривают турниры, профили игроков, статистику, добавляют игроков в избранное
- Система автоматически обновляет турнирные таблицы и рейтинги после ввода результатов
- Telegram-bot рассылает уведомления подписчикам

## UX-цели
- SPA-подобный UX без React: быстрая навигация через HTMX, реактивность через Alpine.js
- Адаптивная вёрстка: одинаково удобно на desktop и mobile
- Real-time обновления через SSE
- Минимальное количество перезагрузок страницы
- Интуитивно понятные дашборды с Chart.js

## Целевая аудитория
- Шахматные болельщики
- Организаторы турниров
- Шахматисты, отслеживающие свой рейтинг
